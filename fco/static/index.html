  2. 만든 앱 → [앱] › [플랫폼 키] › [REST API 키] 를 눌러 키 설정 화면으로 →
    ① REST API 키 값 복사 → 아래 'REST API 키' 칸에
    ② 리다이렉트 URI 에 http://localhost:8765/kakao/callback 추가 → 저장
    ③ 클라이언트 시크릿 의 코드 복사 → 아래 '클라이언트 시크릿' 칸에 (새 키는 기본으로 켜져 있어 꼭 필요)
  3. [카카오 로그인] › [사용 설정] → 상태 ON
  4. [카카오 로그인] › [동의항목] › [접근권한] → 카카오톡 메시지 전송 행의 [설정] → 선택 동의, 동의 목적 아무거나 (예: 나에게 알림) → 저장
  5. [앱] › [제품 링크 관리] › [웹 도메인] → http://localhost:8765 추가 (메시지 버튼 링크용)

갱신 기록

설정

계산식 전체 보기
  • 평일·주말 평균: 최근 28일 일별 가격(데이터센터, 하루 1개 값) 중 월~금 / 토·일의 평균·중앙값.
  • 주말 프리미엄 = (주말 평균 − 평일 평균) ÷ 평일 평균. 반복성: 최근 8번의 주말을 앞뒤 평일과 비교해 오른 주 수를 셈. 절반 미만이면 '일시적'.
  • 할인율 = (평일 평균 − 현재가) ÷ 평일 평균.
  • 인기 스쿼드 점수: 공식경기 1~20위 스쿼드, 1위 20점 … 20위 1점(교체 ×0.5)의 합. 만점 210.
  • 가격 안정성: 30일 CV = 표준편차 ÷ 평균(낮을수록 안정). 급락/급등 = 최근 7일 하루 ±15%, 지속 하락 = 30일 −10% 이하 + 하락 추세, 정체 = 같은 값 5일 이상.
  • 매수 적정가 = 평일 평균 × 할인 계수(30일 CV 0.05 → 0.98, 0.30 → 0.90 선형).
  • 예상 매도가 = 평일 평균 × (1 + 사용 주말 프리미엄). 사용 프리미엄 = max(0, min(공식 프리미엄, 주별 중앙값)), 일시적이면 0.
  • 순수익 = 매도가 × (1 − 수수료율) − 매수가. ROI = 순수익 ÷ 매수가. 손익분기 매도가 = 매수가 ÷ (1 − 수수료율).
  • 목표 매수가 = min(매수 적정가, 예상 매도가 × (1 − 수수료율) ÷ (1 + 최소 목표 수익률)).
  • 판정: 지금 매수 가능 = 현재가 ≤ 목표 매수가 + 위험 없음 / 위험 = 현재가 ≤ 목표가지만 급락·지속하락·정체·당일급락 / 대기 = 현재가 > 목표가.
  • Deal Score: 인기 30 · 할인 25 · 주말 25 · 안정 20. 가격대 그룹 안 백분위(인기만 그룹 최고점 대비 비율). 데이터 없는 지표는 빼고 재환산. 위험 감점 급락 −10, 지속 하락 −15, 당일 급락 −10.
  • 총 운용 BP = 보유한 순 BP + 보유 매물 현재 평가액(현재가 × 수량). 지금 팔면 받는 BP = 평가액 × (1 − 수수료율).
  • 자금 배분 (랭커 픽 기준): 랭커 픽 추천 점수 순. 매수가 = 현재가, 예상 매도가 = 지난 주말 평균. 수수료 20%로 순익 ≥ 매수가 × 목표 수익률이면 쿠폰 없이, 아니면 가장 큰 쿠폰을 쓰면 넘는 경우 쿠폰 매수(1장 판매에 1장, 남은 쿠폰 안에서). 카드당 한도 = 총 운용 BP × 최대 비중 − 그 카드 보유 평가액. 수량 = ⌊min(한도, 남은 순 BP) ÷ 매수가⌋, 단 카드당 최대 수량 · 2시간 거래 ÷ 5 · 남은 쿠폰 이하.
  • 랭커 픽 추천: fc-info 공식경기 인기 팀컬러 20위 팀의 포지션별 10위 카드와 같은 시즌 · 8강 이상(랭커 3명 이상 사용) · 현재가 < 지난 주말 평균 · 2시간 거래 ≥ 5건. 점수 = 거래량 40 (로그) + 픽률 35 + 주말 대비 하락 25, 후보 중 최고값 대비 비율.
  • 보유 매물 평가 손익 = 현재가 × (1 − 수수료율) × 수량 − 매수가 × 수량. 실현 손익 = 매도가 × (1 − 수수료율) × 수량 − 매수가 × 수량.
  • 판매 수수료 = 기본 40% × (1 − PC방 30% − TOP CLASS 20% − 쿠폰). 할인은 곱하지 않고 더하며 0 밑으로 내려가지 않음 (FC STATS 수수료 계산기 안내, 이벤트로 바뀔 수 있음).
  • 쿠폰 절약 = 판매가 × 기본 수수료 × min(쿠폰, 남은 할인 여지). 판매가에 비례하므로 큰 쿠폰을 비싼 판매에 짝지을 때 총 절약이 최대.
  • 탭3 장기투자 (10억 이상): 상승 추세형 = 7일 상승률 25 (+15%에서 만점) · 30일 상승률 25 (+40%에서 만점) · 상승 지속성 20 (30일 log 가격 회귀 R² 50% + 최근 4주 중 오른 주 50%, 최근 10일 꺾이면 ×0.6 · 둔화면 ×0.85) · 인기 순위 15 · 거래량·매물 10 · 급등 위험 5 (7일 +15% 넘으면 감점, 30일 +80% 넘으면 감점, 하루 급등 이력이면 최대 0.3). 저평가 선점형 = 인기 순위 25 · 고점 대비 할인 25 (5%→0, 40%→만점) · 상승 미반영 20 (인기 점수 − 30일 상승 비율, 인기 급등 선수 +0.2) · 14일 안정성 15 (CV 0.10 이하일수록, 14일 −5% 넘게 빠지면 ×0.5) · 거래량·매물 10 · 반등 신호 5. 인기 순위 = fc-info 인기 팀컬러 20위 팀의 포지션 순위 중 최고 (1위 1.00 ~ 10위 0.82, 11~15위 0.72~0.60, 순위권 밖 0.15). 데이터 없는 항목은 빼고 100점 환산. 등급 S 85↑ · A 75↑ · B 65↑ · C 50↑ · D. 매수 적정가: 상승형 = 7일 평균을 현재가 −3~−5% 사이로 (과열이면 7일 평균까지 대기), 저평가형 = (14일 최저 + 14일 중앙값) ÷ 2 (기록 30일 미만 · 14일 CV 0.15 초과면 '분석 데이터 부족').
  • 추천 검증: 갱신할 때마다 그날 처음 추천된 랭커 픽 카드를 그때 현재가로 기록하고, 그 뒤 첫 주말(토·일) 일별 가격 평균에 판 것으로 채점 (수수료 / 쿠폰 두 가지).

일별 가격은 하루 평균이라 실제 이적시장 체결가와 다를 수 있습니다. 매수 전 게임에서 매물 가격을 직접 확인하세요.
